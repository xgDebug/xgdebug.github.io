Influencing People’s Behavior Like Training a Dog Shaping is a learning procedure. In this learning procedure, initially, any behavior similar to the target behavior is rewarded; then the standard is gradually raised, and rewards are given only for behaviors that are increasingly similar to the target behavior; finally, rewards are given only when the target behavior actually occurs.
